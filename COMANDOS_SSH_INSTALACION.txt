🚀 PASO 7: INICIAR LA APLICACIÓN

────────────────────────────────────────────────────────────

🌐 PASO 8: CONFIGURAR SERVIDOR WEB (NGINX/APACHE)
──────────────────────────────────────────────────

La aplicación corre en el puerto 3000 por defecto.
Necesitas configurar un proxy inverso.


# CONFIGURACIÓN NGINX:
─────────────────────

sudo nano /etc/nginx/sites-available/servyauto


# Pegar esta configuración:
────────────────────────────────────────────────────────
server {
    listen 80;
    server_name tudominio.com www.tudominio.com;

    location / {
        proxy_pass http://localhost:3000;
        proxy_http_version 1.1;
        proxy_set_header Upgrade $http_upgrade;
        proxy_set_header Connection 'upgrade';
        proxy_set_header Host $host;
        proxy_cache_bypass $http_upgrade;
        proxy_set_header X-Real-IP $remote_addr;
        proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
        proxy_set_header X-Forwarded-Proto $scheme;
    }
}
────────────────────────────────────────────────────────


# Activar sitio:
sudo ln -s /etc/nginx/sites-available/servyauto /etc/nginx/sites-enabled/


# Verificar configuración:
sudo nginx -t


# Reiniciar Nginx:
sudo systemctl restart nginx


# Configurar SSL con Let's Encrypt (RECOMENDADO):
sudo apt install certbot python3-certbot-nginx
sudo certbot --nginx -d tudominio.com -d www.tudominio.com

❌ SOLUCIÓN DE PROBLEMAS
─────────────────────────

PROBLEMA: "Cannot find module '@prisma/client'"
SOLUCIÓN:
  cd servyauto_manager_v89/app
  yarn prisma generate
  pm2 restart servyauto


PROBLEMA: Error de conexión a la base de datos
SOLUCIÓN:
  - Verifica DATABASE_URL en .env
  - Asegúrate de que PostgreSQL está corriendo
  - Verifica usuario y contraseña
  

PROBLEMA: Puerto 3000 ya en uso
SOLUCIÓN:
  # Cambiar puerto en package.json o usar variable:
  PORT=3001 pm2 start yarn --name "servyauto" -- start


PROBLEMA: La app se detiene sola
SOLUCIÓN:
  # Usar PM2 en vez de yarn start directamente
  # PM2 reinicia automáticamente si la app crashea
