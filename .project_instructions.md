## Database
- PostgreSQL hosted by Abacus.AI
- Prisma model names map to different table names (e.g., Local -> "locales", Cita -> "citas")

## Key Business Rules
- All prices include 21% IVA. Base = total/1.21, IVA = total - base
- MetodoPago: EFECTIVO, TPV_SUMUP, TPV_UNICAJA
- Factura types: EFECTIVO/TPV_SUMUP → TICKET, TPV_UNICAJA → FACTURA
- GSControl sync: Auto-syncs facturas/gastos/cierres to external accounting

## SumUp Integration
- Per-local API keys stored in locales.sumupApiKey / sumupAffiliateKey
- Central fallback key in .env SUMUP_API_KEY
- All API routes resolve local-specific keys via getLocalSumUpKeys()

## Email Reports (Automated)
- **Diario**: 23:00 Europe/Madrid → info@servyauto.com (NOTIF_ID_REPORTE_DIARIO)
- **Semanal**: Lunes 08:00 → info@servyauto.com (NOTIF_ID_REPORTE_SEMANAL)
- **Mensual**: Día 1 del mes 08:00 → info@servyauto.com (NOTIF_ID_REPORTE_MENSUAL)
- **Anual**: 1 Enero 10:00 → info@servyauto.com (NOTIF_ID_REPORTE_ANUAL)
