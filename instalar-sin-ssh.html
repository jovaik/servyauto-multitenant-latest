🚀 Instalación ServyAuto Manager v8.9

Sin acceso SSH - Solo Administrador de Archivos

🎯 OPCIÓN 1: Instalador Web Automático (RECOMENDADO)

Paso 1: Subir el instalador

Sube el archivo instalador-web.php a tu carpeta principal del hosting usando el administrador de archivos.

Paso 2: Ejecutar instalador

Abre tu navegador y ve a:

http://tu-dominio.com/instalador-web.php

Haz clic en "Instalación Completa" y espera a que termine.

🛠️ OPCIÓN 2: A través del Panel de Control del Hosting

📝 Pasos en tu Panel de Hosting:

1. Buscar "Terminal" o "SSH"

Muchos hostings tienen un terminal web en el panel de control. Búscalo en secciones como:

  • "Herramientas Avanzadas"
  • "Terminal Web"
  • "SSH Terminal"
  • "Línea de Comandos"

2. Si encuentras terminal web:

cd /ruta/donde/esta/tu/proyecto
chmod +x install.sh
./install.sh

🔧 OPCIÓN 3: Hosting Específico

cPanel (muy común):

1. Busca "Terminal" en cPanel
2. Ejecuta los comandos de instalación

Hostinger:

1. Ve a "Hosting" > "Administrar"
2. Busca "SSH Access" o "Terminal"

SiteGround:

1. Site Tools > "Dev" > "SSH Keys Manager"

GoDaddy:

1. cPanel > "Terminal"

🆘 OPCIÓN 4: Si nada funciona

Tu hosting podría no soportar Node.js

Muchos hostings compartidos básicos no soportan aplicaciones Node.js. En este caso necesitas:

  • VPS (Servidor Virtual Privado)
  • Hosting especializado en Node.js como:
    • Heroku
    • Vercel
    • Netlify
    • DigitalOcean
    • Railway

✅ Alternativas gratuitas para probar:

  • Vercel: Perfecto para Next.js
  • Railway: Fácil deploy
  • Heroku: Clásico y confiable

📞 Contactar a tu Proveedor de Hosting

Pregunta específica que puedes hacer:

"Hola, necesito instalar una aplicación Node.js (Next.js) en mi hosting. ¿Tienen soporte para Node.js y npm? ¿Cómo puedo ejecutar comandos de instalación?"

Información que debes proporcionar:

  • Es una aplicación Next.js
  • Necesitas ejecutar npm install y npm run build
  • La aplicación usa el puerto 3000
  • Tienes base de datos PostgreSQL configurada

🎉 Una vez instalado:

Tu aplicación estará disponible en:
http://tu-dominio.com:3000

O sin puerto si configuras proxy reverso:
http://tu-dominio.com
