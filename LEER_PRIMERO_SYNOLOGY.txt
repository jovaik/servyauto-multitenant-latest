🚀 INSTALACIÓN RÁPIDA (RESUMEN)
════════════════════════════════


Método recomendado: DOCKER

┌────────────────────────────────────────────────────────────┐
│  PASO 1: Preparar Synology                                 │
└────────────────────────────────────────────────────────────┘

1. Abrir DSM (panel web de Synology)
2. Package Center → Instalar "Container Manager"
3. Package Center → Instalar "PostgreSQL 14"
4. Configurar PostgreSQL:
   - Usuario: servyauto
   - Password: [tu password seguro]
   - Base de datos: servyauto_db


┌────────────────────────────────────────────────────────────┐
│  PASO 2: Subir aplicación                                  │
└────────────────────────────────────────────────────────────┘

1. File Station → Crear carpeta /docker/servyauto
2. Subir servyauto_synology_completo.zip
3. Extraer el ZIP


┌────────────────────────────────────────────────────────────┐
│  PASO 3: Configurar .env                                   │
└────────────────────────────────────────────────────────────┘

Ubicación: /docker/servyauto/servyauto_manager_v89/app/.env

Contenido:
──────────────────────────────────────────────────────────────
DATABASE_URL="postgresql://servyauto:TuPassword@localhost:5432/servyauto_db?schema=public"
NEXTAUTH_URL="http://tu-synology.local:3000"
NEXTAUTH_SECRET="[generar con: openssl rand -base64 32]"
PORT=3000
──────────────────────────────────────────────────────────────

Para generar NEXTAUTH_SECRET:
- Por SSH: openssl rand -base64 32
- Online: https://generate-secret.vercel.app/32


┌────────────────────────────────────────────────────────────┐
│  PASO 4: Desplegar con Docker                              │
└────────────────────────────────────────────────────────────┘

OPCIÓN A - Via Container Manager (sin SSH):
1. Abrir Container Manager
2. Project → Create
3. Project Name: servyauto
4. Path: /docker/servyauto/servyauto_manager_v89
5. Source: Create docker-compose.yml
6. Pegar contenido del archivo docker-compose.yml
7. Done → Esperar a que compile (5-10 min)

OPCIÓN B - Via SSH (más rápido):
ssh admin@tu-synology.local
cd /volume1/docker/servyauto/servyauto_manager_v89
docker-compose up -d


┌────────────────────────────────────────────────────────────┐
│  PASO 5: Inicializar base de datos                         │
└────────────────────────────────────────────────────────────┘

Container Manager → Container → servyauto-app
Details → Terminal → Ejecutar:

yarn prisma db push


┌────────────────────────────────────────────────────────────┐
│  PASO 6: ¡LISTO! Acceder a la aplicación                  │
└────────────────────────────────────────────────────────────┘

Abre tu navegador:
http://tu-synology.local:3000

O usando IP:
http://192.168.1.XXX:3000

Deberías ver la página de LOGIN 🎉

🌐 CONFIGURAR ACCESO DESDE INTERNET (OPCIONAL)
═══════════════════════════════════════════════


Si quieres acceder desde fuera de tu casa:

1. Control Panel → Login Portal → Advanced → Reverse Proxy
2. Create → Configurar:
   - Source: HTTPS, servyauto.tudominio.com, 443
   - Destination: HTTP, localhost, 3000

3. Control Panel → Security → Certificate
   - Add → Let's Encrypt
   - Domain: servyauto.tudominio.com

4. En tu router: Port Forwarding
   - Puerto 443 → IP de Synology

5. Control Panel → External Access → DDNS
   - Configurar dominio (ej: tuservyauto.synology.me)

6. Actualizar .env:
   NEXTAUTH_URL="https://servyauto.tudominio.com"

7. Reiniciar contenedor

❓ ¿PROBLEMAS?
══════════════

Si algo no funciona:

1. Verifica logs:
   Container Manager → Container → servyauto-app → Details → Log

2. Verifica que PostgreSQL está corriendo:
   Container Manager → Container → postgres-servyauto

3. Verifica archivo .env:
   File Station → /docker/servyauto/.../app/.env

4. Consulta la sección "Solución de Problemas" en:
   INSTALACION_SYNOLOGY.md
