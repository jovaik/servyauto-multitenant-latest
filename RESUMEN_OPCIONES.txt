❌ POR QUÉ NO FUNCIONA EN RESELLERCLUB:
═══════════════════════════════════════

ResellerClub es un hosting compartido diseñado para:
  • Sitios web PHP (WordPress, Joomla, etc.)
  • Contenido estático (HTML, CSS, JS)
  • NO para aplicaciones Node.js

ServyAuto Manager v8.9 necesita:
  • Node.js v18+
  • Servidor que ejecute comandos permanentemente
  • PostgreSQL
  • Proceso activo 24/7

┌──────────────────────────────────────────────────────────┐
│  OPCIÓN 3: MANTENER RESELLERCLUB SOLO PARA EL DOMINIO   │
└──────────────────────────────────────────────────────────┘

✓ No pierdes tu inversión en ResellerClub
✓ Usas Vercel/Hostinger para la aplicación
✓ Tu dominio apunta a la nueva ubicación

PASOS:
1. Desplegar app en Vercel o Hostinger
2. En ResellerClub → DNS Management
3. Crear registro CNAME:
   Host: www
   Apunta a: cname.vercel-dns.com (o IP de Hostinger)
4. Guardar cambios (propaga en 24-48h)

TIEMPO: 15 minutos (+ tiempo de propagación DNS)
